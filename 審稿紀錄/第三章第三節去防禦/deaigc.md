# 第三章第三節〈細讀程序與記錄格式〉去AI味掃描報告

掃描範圍：`---` 之前正文十三段。依 `chinese-de-aigc` 十七類（P01–P17）逐類檢查，並對照《論文寫作要求（定版）》第5–13條。細讀程序規格所需的分號長句、無主句、「記為／錄下／入檔／入簿／為準／一律」等程序語，以及「理論架構所立／語境考察所誌」一類以內容名代章節號的回指，均視為文類所需，不列入。十七類之中，P01、P03、P04、P10、P11、P12、P14、P15、P16、P17 未見觸發；P05、P06、P07、P08 的觸發屬文類所需，不報。下列十條為真正的問題。

---

**1. 第13條（比喻構詞擴散）——「賬」系記帳比喻**

原句：「緣於理論架構所立同一文本片段不計兩賬的約定」「教化之處所宣示的價值歸價值層一賬」「共用證據如何計賬，由判定規則寫定」「一律明標為推斷，不與文本內的直接判定同賬」「符號一賬的名稱字串與話語一賬的評價語兩者不相交」「兩賬互記對方的起訖」。

診斷：「賬」為會計比喻，本節出現九次，衍出「一賬／兩賬／同賬／計賬／歸…一賬」五種變體，違反第13條「禁比喻構詞」與「不擴散不變體」。

改法：若理論架構已以「不計兩賬」立約，保留該一處作為回指；其餘改為非比喻表述——「歸價值層登記」「共用證據如何計數」「不與文本內的直接判定並列計數」「符號層所登的名稱字串與話語層所登的評價語兩者不相交」「兩層互記對方的起訖」。

**2. 第13條（比喻構詞與壓縮詞）——「供料」「入判」「入單」「定表」**

原句：「痕跡登記單獨先行，各層通用，為各層供料」「反覆的次數只定何者入判」「凡語境考察以社會構成、機構格局之名及理論架構以三段時間、反向運動之名明列者盡數入單」「語料表的資格判準於細讀之前定表，其修訂止於定表，不入此簿」。

診斷：「供料」是工序／原料比喻；「入判」「入單」「定表」為二字壓縮，望文難以知義（「入判」尤易誤讀為「入判定簿」之省），不合第13條「望文知義或文獻有用例」的基準。

改法：「供各層取用」；「只定何者列入判定」；「盡數列入名單」；「於細讀之前寫定，其修訂止於寫定之時」。

**3. 第13條（術語紀律，兼涉第33條同義異詞）——「斷裂組態簿」之「組態」**

原句：「斷裂組態簿收某一維度的觀察項在本件全無可登之處，以及維度之間相互牴牾的文本」「次依最終判定歸斷裂組態簿」。

診斷：寫作要求第29條以「構型清點」為方法貢獻之名，「組態」與「構型」同為 configuration 的譯名；若所指為同一概念，即跨章同義異詞。本節「構型」零見、「組態」兩見。

改法：對照術語總表，若同指則一律改「構型」（「斷裂構型簿」）；若「組態」另有所指，須於首現處說明其與「構型」之別。

**4. 第13條（比喻構詞／公文腔）——「免檢預設」**

原句：「免檢預設的判定憑兩者對照，並記明人物的質疑、敘述者的論證或改口與情節的反證三處皆無所見」「登記為被反證的預設，不計免檢」。

診斷：「免檢」為商檢／行政用語（免檢產品），移作預設之名屬比喻構詞；本節首現無定義。

改法：若理論架構已定名並入術語總表，首現處補「即理論架構所稱」回指即可；否則改「未經檢驗的預設」或「不受質疑的預設」，兩處同改。

**5. 第7條（對稱收束）——兩段段末同一「只改A，不動B」式**

原句：「類型的歸併於同一時點完成，只改編排，不動逐條登記；合讀只核對兩數，不另清點。」（觀察項段末）「重排與彙齊改動的只是編排，判定與計數仍依各輪封存之檔。」（檔案登記段末）

診斷：兩段段末皆以「只A／不B」雙重反題收束，內容又互相重複（編排可改、判定不動），是模板式段尾，第7條尤禁段末。

改法：前者改「類型的歸併於同一時點完成，逐條登記不動；合讀只核對兩數。」後者刪去對稱半句：「重排與彙齊之後，判定與計數仍依各輪封存之檔。」

**6. 機器腔（P02 類虛詞／套語複沓）——「由判定規則寫定」疊句**

原句：「門檻由判定規則寫定」「判法由判定規則寫定」「共用證據如何計賬，由判定規則寫定」「可整體替換與不可替換兩種登記的證據力由判定規則寫定」「細則由判定規則寫定」「三類登記的界線由判定規則裁定」「拆後如何計數，屬判定規則的事務」。

診斷：同一後置分句七次收尾，加上「依判定規則」各處，全節「判定規則」二十五見，讀來如同機器填充的固定尾綴。

改法：於本節首段或痕跡登記段加一句總括：「凡門檻、判法、證據力、計數與各類登記的界線，均於判定規則寫定」；此後各處只留一兩處必要回指，其餘刪去尾綴，句子直接以規則內容收束。

**7. 第6條（禁口語）——四處口語詞**

原句：「找不到可登記之區分者，記為我方與他方未分」「人物解釋的連同文本給他的稱謂與角色名詞」「可在任何城市照樣建造者」「誰能進入何處、誰被擋在何處」。

診斷：「找不到」「給他的」「照樣」「擋在」為口語用詞，與全節文言傾向的語體不合。

改法：「無可登記之區分者」；「連同文本賦予該人物的稱謂與角色名詞」；「可在任何城市依樣建造者」；「誰被阻於何處」。

**8. 第6條／語體一致——枚舉收尾兩極：「這些」七處與「之屬」九處**

原句：「只見、原來、心想這些轉入人物視點的詞語」「引號、叫做與所謂這些引導語」「著名的、美麗的這些定語」「平台、政策與教育體系這些生產條件」；「巴士、士多、菲傭之屬」「澳督、葡幣之屬」「幹嘛、好嘞之屬」「中葡並處、博彩與半島地形之屬」。

診斷：枚舉收尾只用兩個模子，一半是口語體的「X、Y這些N」，一半是文言體的「X、Y之屬」，各自機械複沓，語體又互相打架。

改法：「這些」改「一類」或「等」（「只見、原來、心想一類轉入人物視點的詞語」）；「之屬」減至三四處，其餘改「之類」「一類」，或枚舉後直接接謂語不加收尾（「澳督、葡幣另標」）。

**9. P09（句法累贅）——「一處……一處之處」**

原句：「一處可兼記，兼記之處即文本把數環再組合於一處之處」。

診斷：一句之內「一處」兩見、「之處」兩見，「於一處之處」尤為疊床架屋，語義雖通，讀感機械。

改法：「一處可兼記，兼記即文本把數環再組合於同一場所。」

**10. 第10條（公文腔指示詞）——行文中的「下列」**

原句：「第一人稱兒童敘述中的不加解釋，須另有下列三者之一，對齊的安排所錄敘述者對讀者的招呼與提問、副文本所示的發話對象、同件他處對同類本地事項的解釋，方可據以判定隱含讀者⁴⁴的設定」。

診斷：「下列」是條例與公文的指示詞，用於流動散文而其後並無列表，只以同位語接續，既是公文腔，又使句子前後脫節。

改法：「第一人稱兒童敘述中的不加解釋，須另見敘述者對讀者的招呼與提問（取自對齊的安排）、副文本所示的發話對象，或同件他處對同類本地事項的解釋三者之一，方可據以判定隱含讀者⁴⁴的設定」。

**總評**：本節無四字套話、段首連接詞、序數鏈、絕對化斷言與回音壁等高危模式，長短句落差大，整體不帶典型機器腔；真正的問題集中在術語紀律（「賬」系比喻、「供料」「免檢」、「組態／構型」待對表）與少數複沓模板（「由判定規則寫定」尾綴、段末「只A不B」對稱、「這些／之屬」枚舉收尾），改訖即可；另「位點」二十三見係生物學借詞、「回接」首段首現而至第二段方見界定，請核術語總表，未收則補首現定義。
