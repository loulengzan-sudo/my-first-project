## 一、【高】歷史題材「不解釋媽閣廟是什麼」與本件登記相違

逐字原句：「這些文本解釋的是孫中山為什麼在草堆街行醫、一六二二年山下發生過什麼、蝦蟆石何以得名、醉龍節從哪裡來，卻不解釋草堆街在哪裡、東望洋山是哪座山、媽閣廟是什麼。」

問題：U11 S02 登「媽祖閣｜有解釋：E01｜外地讀者所缺的地方知識」，原件 W25 頁21：「我跟老師來到媽祖閣參觀，現在導賞員正作最後的總結，這裡是澳門現存廟宇中有實物可考的最古老的廟宇，也是澳門文物中原建築物保存至今時間最長的」，正是本節第三層所計〈三石〉七次地方知識解釋之首，受話者為學生（本地兒童）。草堆街亦有相對定位：W15 頁065「因為草堆街前方便是熙熙攘攘的十月初五街」，頁066「那時的康公廟和十月初五街就在海岸邊」。又原件三處作「媽祖閣」（頁21、24）、一處作「媽閣廟」（頁22），正文當用文本所取之名。

可貼回改句：「這些文本解釋的是孫中山為什麼在草堆街行醫、一六二二年山下發生過什麼、蝦蟆石何以得名、醉龍節從哪裡來；對地方本身的說明不是沒有，〈三石〉的導賞員開篇即稱媽祖閣『是澳門現存廟宇中有實物可考的最古老的廟宇』（件二十五，頁21），〈草堆街醫學之旅〉也以『草堆街前方便是熙熙攘攘的十月初五街』（件十五，頁065）給出街的所在，但這類說明在歷史題材幾件之中只佔少數，東望洋山是哪座山、海角遊魂在城的哪一角，自始至終未見交代。」

## 二、【高】三處發話者與受話者的歸屬與原件不合

逐字原句：「〈一六二二年〉的絡腮鬍子問祖西『你對大炮台的印象如何』（件十四，頁033）」；「〈豆丁和他最愛吃的「豆腐花」〉裡店家口中的「熱花」（件二十三，頁9）」；「〈路環「七星伴月」傳說〉裡村民口中的「譚公爺爺」（件十，頁06）」。

問題：祖西不是外來者。W14 頁033「祖西又一次來到大炮台」，頁036「這是他平常接觸的大炮台，一個充滿歡笑聲的地方」；T07 記祖西身份「文本未明言」。所引一句是提問而非解釋，解釋者反而是祖西，E03 記祖西向絡腮鬍子說「一個旅遊景點，一個很舒服的地方」。以此例證「外來者受話」，方向正相反。「熱花」出自敘述語言，W23 頁9：「豆丁……更不忘多點一碗“熱花”（熱豆腐花）解解饞」，無店家發話。「譚公爺爺」是敘述者轉述，W10 頁06：「曾經有人告訴她，譚公爺爺經常變成小孩的樣子」。本節以受話者身份為第二層立論的樞紐，例證的歸屬須與痕跡記錄一致。

可貼回改句（第二層）：「有時是一位外來者，〈東望洋山尋寶記〉的松德向從香港來的智財介紹『這是東望洋燈塔，建於一八六五年前，是中國海岸第一座燈塔』（件十六，頁121），〈小王子寶石城之旅〉的媽祖向小王子自報『我是媽祖娘娘──這座小城的守護神』（件七，頁03），〈當天使飛過松山〉的小肥豬向初來的小飛馬說『你明天去二龍喉公園走走』（件一，第五段）。〈一六二二年〉的方向相反：常到大炮台的本地孩子祖西把大炮台說成『一個旅遊景點，一個很舒服的地方』（件十四，頁033），聽的是來自四百年前的絡腮鬍子，受話者是歷史中人而非外人。」
可貼回改句（第一層）：「再有口語的省稱與親稱，〈豆丁和他最愛吃的「豆腐花」〉的敘述語言寫豆丁『多點一碗「熱花」（熱豆腐花）』（件二十三，頁9），〈路環「七星伴月」傳說〉的敘述者轉述村中人語，稱『譚公爺爺』（件十，頁06）。」

## 三、【高】「葡文正名與音譯官方名一次也不出現」須收窄；譚僊聖廟類屬與出處待核

逐字原句：「澳門的街道與建築多有中葡兩套正名，新馬路的官方名是亞美打利庇盧大馬路，大三巴牌坊的官方名是聖保祿學院天主之母教堂遺址，譚公廟在文物名錄裡是譚僊聖廟。二十六件文本之中，葡文正名與音譯官方名一次也不出現，新馬路只作新馬路（件十一，頁3），譚公廟只作譚公廟，紅街市只作紅街市。」

問題：二十六件全文逐一檢索，以葡人人名音譯而成的街名與建築名確無一見（亞美打利庇盧、嘉思欄、高士德、肥利喇、羅理基、美副將等皆零）。但「音譯官方名」有：格蘭披治大賽車（W17 頁185「一年一度的格蘭披治大賽車」，U25 S50 名稱語源登「葡文音譯」），大三巴（「三巴」為 São Paulo 音譯，U15、U08 皆如此登記）。葡文對譯之官方名也有：十月初五街（Rua de Cinco de Outubro，W15 頁065、W23 頁10）、聖母雪地殿教堂（W16 頁121）、仁慈堂（W15 頁066）。譚僊聖廟既非葡文亦非音譯，列於「中葡兩套正名」之下類屬不合；且名錄原始 MC002 記「譚公廟……另稱：譚僊聖廟」（名錄_不動產.md 第79行），正名與另稱的方向與正文所述相反，待核 culturalheritage.mo/detail/100021。地方知識名單記文物名錄取用 2026-11-11、網站未標版本日，依第三章第三節「所取用的版本年份隨判定規則記明」，正文斷言名錄所載時應交代版本。另有三處可用而未用的材料：W06 頁22「我發覺路牌寫着“海角遊雲”，而不是老師所説的“海角遊魂”，是怕引起人們恐慌而改了名字嗎」是全表唯一把官方名與俗稱之別寫進情節的一處；W04 第五段「山頂醫院」是仁伯爵綜合醫院的俗稱；W06、W15 的「澳門街」與 W15 頁070 的「濠江」是城名的俗稱與別名。

可貼回改句：「澳門的街道與建築多有中葡兩套正名，新馬路的官方名是亞美打利庇盧大馬路，山頂醫院的官方名是仁伯爵綜合醫院。二十六件文本之中，以葡人人名與葡語詞音譯而成的街道與建築正名一次也不出現：新馬路只作新馬路（件十一，頁3），〈龜兔競賽〉送傷者去的是山頂醫院（件四，第五段）。進入文本的葡源名稱只有兩類，一類是早已入粵語口語的音譯，大三巴（件二十三，頁9）、格蘭披治大賽車（件十七，頁185）；一類是以漢語意譯通行的名稱，十月初五街（件十五，頁065）、聖母雪地殿教堂（件十六，頁121）。官方名與俗稱之別被寫進情節的只有一處，〈海角遊魂的鬼故〉的小強發覺『路牌寫着「海角遊雲」，而不是老師所説的「海角遊魂」』（件六，頁22），路牌上的官方名在故事裡反成了須加揣測的異名。」

## 四、【高】沃爾三分的套用與判定規則相斥，譯名無據

逐字原句：「沃爾⁴⁵所分的單一受話、雙重受話與雙聲受話，在這裡有了地方知識層面的對應，外來者受話的解釋正是雙聲受話的一種形態，故事裡的孩子與故事外的孩子同時被告知。」

問題：沃爾的 single／double／dual address 分的是敘述者對兒童與成人兩種隱含讀者的發話姿態，不涉故事內人物之間的聽說關係；把故事內受話者套入此分類是類屬錯置，「故事裡的孩子與故事外的孩子同時被告知」並非 dual address 之義。判定規則第17段明定「沃爾⁴⁵所論成人與兒童受述者之分……只及被解釋事項屬成人世界知識的一值，不入讀者設定的三值」，本段用法與既定規則相斥（第0條、第35條）。三個譯名第二章未立、首現未附原文（第36條），「雙聲受話」無文獻用例（第13條）；「受話者」與第二章「受述者」、細讀程序「受解釋者」三名並用（第33條）。「外來者是兒童文學裡慣用的裝置」無引註（第15條）。

可貼回改句：「外來者在這裡承擔的是敘述說明的人物化：讀者所缺的知識由故事中人說給另一個故事中人，解釋因此不必直接向讀者發出，讀者的位置被安放在受解釋者身後。這正是錢伯斯⁴⁶所說的文本假定讀者須為解釋之事，只是改由對話承擔；斯蒂芬斯⁵³所論位置不靠聲明而靠敘事技術製造，於此得到一個地方知識層面的實例。」

## 六、【高】〈飛走的泳棚〉「解釋的全是今日已失的所在」與登記相違

逐字原句：「〈飛走的泳棚〉四十六次之中十二次有解釋，解釋的全是一九八五年已有而今日已失的所在，它所設想的讀者並非外地人，是不曾見過泳棚的本地孩子，解釋跨越的是時間而非地方」；「泳棚、圓台仔、大井、貯水塘一一交代」。

問題：U25 有解釋且屬地方知識者包括漁翁街（S01）、友誼大橋（S02）、貯水塘（S07）、新港澳碼頭（S08）、格蘭披治大賽車（S50、S65）、漁翁彎與水塘角（S66、S67），皆今日尚在；原件頁181「漁翁街的海堤邊還沒有友誼大橋的時候」更以今物為讀者可知的座標。今已失者只泳棚、圓台仔、木屋區、可口可樂模型，而圓台仔、大井、木屋區、可口可樂模型在案例簿皆「暫不裁入（待核）」（第44、53、58、94行），第二層自稱「對名單內的地方符號」卻舉圓台仔、大井為例，口徑不合。

可貼回改句：「〈飛走的泳棚〉四十六次之中十二次有解釋，解釋分兩路：泳棚、木屋區一類一九八五年已有而今日已失的所在，由敘述者逐一交代其形制；漁翁街、水塘、格蘭披治大賽車一類今日尚在的所在，則被當作讀者可憑以定位的座標，『漁翁街的海堤邊還沒有友誼大橋的時候』（件十七，頁181）一句以今物標舊景。它所設想的讀者是認得漁翁街卻不曾見過泳棚的本地孩子，解釋跨越的主要是時間而非地方。」第二層例句改為「泳棚、貯水塘一一交代」。

## 七、【中】件級判定復算：「分佈不變」不成立；劏狗環的舊名歸屬自相矛盾；條目體

逐字原句：「二十六件之中，可計符號全為不加解釋者四件，讀者設定記為本地讀者：……可計符號全為有解釋者零件，沒有一件文本把讀者設為對澳門一無所知的外人。兩類並見者二十件，記為混合；兩件無名單內符號可計，記為無可登（件九、件十九）。」；「含與不含判定邊界案例簿裁入之件兩列並陳，分佈不變。」

問題：依 reader_setting.json 與原件復算三件。件二十（U21）：三十三次符號名單內數為零，六次可計全來自案例簿裁入的澳門大學（第126行）與劃地為澳（第38行）；含裁入為混合（有解釋四：S01、S04、S15、S31；不加二：S05、S10，與 json 相符），不含裁入則為無可登，二十／二應作十九／三，「分佈不變」不成立，且「唯一解釋多於不解釋的一件」全賴裁入符號，須言明。件六（U16）：名單內三符號一六二二年葡荷之戰、馬交石、馬交石炮台皆不加解釋；裁入海角遊魂等後，有解釋者七次來歷、一次成人世界，兩列皆本地讀者，與 json 相符。件二十五（U11）：媽祖閣 S02 有解釋屬地方知識，S18、S24、S27 不加，兩列皆混合；但 json 之解釋七次含 S14「紅樹林及白鷺群」像似細描，案例簿第3行明言「像似細描不以名稱入名單，不作此裁」，應為六次；E03 以海上航線沿途所見列舉澳門半島、氹仔、路環而登為三處之地方知識解釋，列舉所見與說明其地有別，宜入邊界案例。另案例簿第39行劏狗環「裁為地方知識｜黑沙環舊名（待核）」，與第3行「未能核實者不裁入」相違；劏狗環若為舊名，U16 S10 登「不適用」有誤，舊名當為三處，〈海角遊魂的鬼故〉寫一六二二年用當時之名，「兩處之外，二十六件一律以今名稱今物」隨之不成立，須擇一改正。段式「X者記為Y」為第13a條所禁。規則原文為「全為有解釋或有標記者，記外地讀者」，「全為有解釋者零件」漏標記一值。

可貼回改句：「依判定規則計算，二十六件分成四類。可計符號全不加解釋的四件把讀者設為本地人：〈披着白毛毛的小妖怪〉與〈尋找時間的小黑貓〉把二龍喉公園、紅街市當作無須說明的所在，〈海角遊魂的鬼故〉與〈燈塔的守護〉所有的解釋都落在來歷一端。沒有一件把可計符號全數加以解釋或標記，沒有一件把讀者設為對澳門一無所知的外人。兩類並見的二十件為混合，〈想當作家的小姑娘〉與〈澳門小王子放學路上〉無名單內符號可計。案例簿裁入的符號只改動一件的歸類：〈跳到對岸去〉的可計符號全出自裁入的澳門大學與劃地為澳，含之為混合，去之則無可登，混合二十件與十九件兩列並陳，本地讀者四件與外地讀者零件兩列相同。」

## 八、【中】名稱形式的計數口徑無法由登記復得；「二十二處」所指不明

逐字原句：「七百三十四次地方符號之中，有官方名與俗稱之分可辨的一百九十三次：官方名一百零二次，俗稱八十次，文本所用之名本身就是兩個並存官方名之一者七次，舊名兩次，另兩次是官方名帶稱謂」；「人物講解的二十二處另有一種安排：解釋在故事裡有一位受話者。」

問題：符號層檔案名稱形式欄無一口徑得出此數：全部條目官方名一百零五、俗稱八十六、並存六；去外部地點後一百零四、六十三、六；只計名單內則一百零一、三十四、六；「七次」須把〈相互補足〉「魚行團結日」登記的「並存名稱」併入並存官方名方得。第一節已立名單內口徑為六十個符號、二百五十九次，本段未說明一百九十三次依何而計，各章數字口徑須一致（第34條）。人物講解四十六處依登記規範皆記受話者，「二十二處另有一種安排」所指不明；餘二十四處當是向故事中成人發出或自語，依規則不入讀者設定之計，應點出。

可貼回改句：「名稱的選擇先看全表。七百三十四次地方符號之中，名單內並有官方名與俗稱之分可辨的〔依核定口徑填入〕次：官方名〔〕次，俗稱〔〕次，文本所用之名本身就是並存官方名之一者〔〕次，舊名兩次，另兩次是官方名帶稱謂；計數只及名單內與案例簿裁入之符號，外部地點與像似細描不計。」「人物講解四十六處之中，二十二處的受話者是故事裡的本地兒童或外來者，其餘向故事中成人發出或為自語，依判定規則不入讀者設定之計。」

## 九、【中】「只能是本地的孩子」未考慮領域內的替代解釋；段末格言；生產條件口徑

逐字原句：「地方被當作已知，地方的歷史被當作未知：這是這批文本的解釋在知識上的分工，也是它們設定讀者的方式。被告知歷史而不被告知地名的讀者，只能是本地的孩子。」；「這一位置與語料表所記的生產條件相合：二十六件之中二十五件經本地的選家之手，刊於本地兒童所讀的刊物與選集，向外地讀者介紹澳門不是它們的任務。」

問題：「只能」排除了至少四種領域內常見的解釋，第31條要求先立最強版本再說明何以不取。其一，歷史題材幾件皆以學校任務為情節框架（〈相互補足〉調查報告、〈三石〉導賞總結與課堂提問、〈草堆街醫學之旅〉紀念館、〈東望洋山尋寶記〉學生講解），來歷解釋是情節任務，屬鄉土教育體裁慣例，與讀者所缺何種知識無必然關係。其二，第三章第二節第72、76行所記《童一枝筆》十年一貫的徵集建制、選家與作家重合、作者多為教師，來歷多而地名少可由徵稿題材與教師寫法解釋。其三，四件本地讀者之作可計符號僅五、十、九、二十五次，「全為不加解釋」在短篇幅、低符號密度下證據力弱。其四，文學地名學自身的立場是真實地名對外人仍可作寫實質地而不必解釋（即所引⁹¹之說），不解釋地名因此不足以單獨推出本地讀者。段末兩句為格言式收束（第7條）。「二十五件經本地的選家之手」非語料表口徑：第三章第二節為民間創作二十五件、官方委製一件，《澳門日報》三件為報刊發表，官方委製一件亦出本地編者之手。

可貼回改句：「地方被當作已知而地方的歷史被當作未知，是這批文本在知識給予上的分工。依判定規則，這一分工把讀者記為本地讀者；但同一分工也與另外幾種解釋相容：歷史題材幾件都以學校任務為情節框架，調查報告、導賞總結、課堂提問本就以來歷為內容，來歷之多未必出於對讀者所缺的估計；語料表所記的生產條件，《童一枝筆》十年一貫的徵集建制、作者與選家多為本地教師與寫作者，也足以解釋題材的取向。本研究不以這幾種解釋為替代而以為補充，理由在於它們說明了來歷何以多，卻不說明地名何以一律不加解釋：徵稿與課堂都不禁止交代地名，不交代是作者的選擇，而選擇所假定的讀者位置正是這裡要讀出的東西。」「這一位置與語料表所記的生產條件相合：民間創作二十五件與官方委製一件都刊於本地的刊物與選集，經本地的編者與選家之手，向外地讀者介紹澳門不是它們的任務。」

## 十、【中】[88][89][91] 的轉述超出或背離原文

逐字原句：「對澳門街名的專門考察則指出，中葡兩套街名並非互譯，而是兩個平行的命名系統，各有其使用者⁸⁸，氹仔一名的官譯名與舊稱龍頭灣、潭仔之間同樣有一段並行而非替代的歷史⁸⁹。」；「小說中的地名對熟悉其所指的讀者是把地方召到眼前的提示，對不熟悉者則只是陌生的音節⁹¹」。

問題：核實紀錄摘錄金國平原文「過去曾經稱龍頭灣（環）、潭仔，葡文則有 TAIPA……今人則普稱氹仔」，是歷時相承而非並行，「並行而非替代」與原文相背；「氹仔一名的官譯名」語義不通，氹仔是漢名，Taipa 是葡名，何者源於何者正是該文考源之題。[88] 核實紀錄只及「非互譯而為兩套平行系統」，「各有其使用者」無據。[91] 的論點是地名對熟悉者「召現」地方並使人安居其中，「陌生的音節」非其表述，屬加詞（第36條）。

可貼回改句：「對澳門街名的專門考察指出，同一處的中葡名稱常非互譯，而是兩套平行的命名系統⁸⁸；氹仔一地歷稱龍頭灣、潭仔而今普稱氹仔，葡名 Taipa 另有其源，中葡兩名各自成系而非一方譯自另一方⁸⁹。」「文學地名學近年的研究指出，小說中的真實地名對熟悉其所指的讀者是把地方召到眼前、使人在其中安居的提示⁹¹；這批文本的作者把讀者放在這一位置。」
