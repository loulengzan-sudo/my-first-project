# ARS-2 方法論審稿人 — 第二輪（定稿複審）

審查對象：第三章第三節〈細讀程序與記錄格式〉06:40 定稿。第一輪十二條逐條核對，已落實且無新問題者不列（第4條時距與重判規格、第6條副文本與版面摘句、第9條文化層、第10條缺席清單三值與輪次分派、第11條五簿分立，皆已落實）。語料例句已到 語料/分析用全文/ 逐字核對。

**1.【落實查核】中等 — 封存憑證仍是自證，作業用本仍洩漏時段（第一輪第1、3條部分未落實）**

位置：「封存以版本控制系統的提交紀錄為憑，提交識別碼與時間戳記記入修訂簿」「時距以提交紀錄的時間戳記為憑」「作業用本只留語料編號與正文，登記所據一律限於校定本的字句，年份、來源與生產方式留待回接時取用」。

問題：提交時間戳由提交者自設，單人研究以此為四週、八週時距之憑，仍是自己為自己作證；第一輪所提第三方存證未採。語料編號依年份順排，W01–W13 恰為前段、W14–W26 恰為後段（第二節語料表），作業用本去掉檔頭年份而留編號，時段一望可知，隱去之功落空。

改法：「封存以版本控制系統的提交紀錄為憑，提交識別碼與時間戳記記入修訂簿，每次封存並推送至指導教授可讀的遠端倉庫，時距以遠端接收時間為憑」；「作業用本只留正文與該輪隨機派發的作業碼，作業碼與語料編號的對照表隨該輪封存，登記於封存時回填語料編號」。

**2.【落實查核】中等 — 校定陳述與語料庫實況仍有四處不合（第一輪第5條部分未落實）**

位置：「出版方排版文字層的十六件與作者網站轉載的四件，刪去頁碼、書眉與重複的篇名署名後逐字對照底本，只刪不改」「校定本照錄原刊用字」「經兩次互不參看的逐字過錄與比對⋯⋯過錄以視覺辨讀模型完成，模型名稱、版本與提示語記於校定細則，研究者逐頁覆核」。

問題：(a) 網頁四件無頁碼書眉可刪，語料庫 README 載其所刪為網站導航、上下篇連結與 cookie 說明，所對照者是前次爬取存檔而非底本，且「報端原版未見」，「照錄原刊用字」對此四件不成立。(b) 兩次過錄是否同一模型兩跑未交代；同一模型同一提示重跑，分歧只能測隨機誤差，測不出系統性誤讀；語料庫已另以機器 OCR 逐行核查漏行（coverage.py，裁決紀錄載 W16 頁111、121 與 W17 頁183 的弱匹配行經核無漏），這一道獨立檢核反而未寫入正文。(c) 現存轉錄規範與核查報告皆未載模型名稱與版本，「記於校定細則」尚未成立。(d)「視覺辨讀模型」無學科用例，違第13條。

改法：「出版方排版文字層的十六件，刪去頁碼、書眉與重複的篇名署名後逐字對照底本，只刪不改；作者網站轉載的四件無原刊可對，照錄轉載本用字，只刪網站導航與連結，與前後兩次爬取存檔逐字比對一致」；「兩次過錄由同一視覺語言模型以同一提示語分別完成，互不參看，比對之後另以光學字元辨識逐行核查有無漏行；模型名稱、版本與提示語記於校定細則」，並同步補入語料庫的轉錄規範。

**3.【落實查核】中等 — 痕跡登記仍含一項判讀（第一輪第2條部分未落實）**

位置：「並記所補的是年齡所缺的常識還是外地讀者所缺的地方知識」；對照符號層「某一符號是否本須解釋，以語境考察所誌、外埠同齡讀者無從得知的地方知識為準；屬成人世界而非地方特有的知識，其解釋與否歸入沃爾⁴⁵所論文類不對稱的考察」。

問題：痕跡登記自稱「只登記、不裁決」，但「地方知識／年齡常識」之分正是符號層判定「本須解釋」所用的同一判準；在通讀時先行歸類，等於把符號層判定前移到各層共用的痕跡檔，價值層一輪取用全部四欄時隨之讀到，互不參照之約由此開一缺口。

改法：痕跡登記只錄「所解釋的對象（原文字串）、解釋的形式、解釋者、受解釋者及其身份」，刪「並記所補的是年齡所缺的常識還是外地讀者所缺的地方知識」；地方知識與通用知識之分留在符號層依對照名單判定，價值層解釋權一項所需的「外地讀者所缺的地方常識，還是本地兒童亦未必知曉的來歷與典故」由價值層自行就痕跡條目再判。

**4.【落實查核】中等 — 方陣的兩項省略無位點可登，行動者三值不互斥（第一輪第7條部分未落實）**

位置：「評價語言一項，錄下敘述語言、人物語言與副文本三個層次下判斷之處」「每一涉及我他之分的評價先記其出自敘述語言還是哪一位人物之口，再相對於所登記的劃分歸入四項之一」；「記每一行動者被納入、被排除，或被壓成無名之類，納入者並記以本名、親屬稱謂、職稱還是類名指稱」。

問題：「淡化我方之失」「抹去他方之善」是不下判斷之處，登記單位既為「下判斷之處」，此兩項無字句可記；第一輪所提以文本內對應事件或人群為對照位點的改法未落實，兩項登記不可重複。行動者三值中「壓成無名之類」在梵·勒文框架⁷²屬納入之下的類化與同化，與「納入⋯⋯以類名指稱」重疊，三值不互斥。

改法：「淡化與抹去兩項以省略為據，登記時指出文本內同一事件或人群在他處所受的評價或情節後果為對照位點，錄對照處起訖；無對照位點者不登，另欄枚舉」；「記每一行動者被納入抑或被排除，納入者再記以本名、親屬稱謂或職稱指稱，還是以類名壓成無名之類」。

**5.【落實查核】中等 — 可替換性測試的斷裂判準未立，「斷裂位點」一詞二義（第一輪第8條部分未落實）**

位置：「對照城市無對應項者保留原名，記為斷裂位點」；「替換之後，從事件鏈、人物動機與結局三處檢視敘事能否成立，斷裂處記下位點及其所繫的符號」。

問題：何謂「不能成立」仍無判準，第一輪所提三項（與對照城市史地常識牴觸／事件鏈某環失所繫／動機或結局失所繫）未入，「三類登記的界線由判定規則裁定」只管三類之界，不管斷裂之認定，而斷裂認定是登記位點，屬此節之事。「斷裂位點」又兼二義：一指對應表無對應項，二指替換後敘事斷裂；前者未經檢視即稱斷裂，枚舉時與後者無法分開。

改法：「對照城市無對應項者保留原名，記為無對應位點，仍入替換後的檢視」；「替換之後，事件鏈某一環、人物動機或結局因名稱更換而失其所繫，或與對照城市的史地常識相牴，見其一即記為斷裂，錄位點及所繫的符號」。

**6.【新問題】重大 — 重判反序與文化層、場域層的取用規定相斥（第35條）**

位置：「作文化層與場域層兩輪時，得讀已封存的符號層檔案，只讀不改，以追溯指示符號的來歷、登記符號的空間分佈，照理論架構交給兩層的分工」；「重判自痕跡登記重做起，閱讀次序另排，層序與初判相反，價值層居首、符號層居末，兩層之間同樣相隔不少於四週，各輪不讀初判的任何檔案」。

問題：反序本身是已裁決事項，不重審；其後果未處理。重判中符號層居末，文化層與場域層兩輪進行時，重判的符號層檔案尚不存在，初判的又不得讀，兩輪所依的「指示符號的來歷」「符號的空間分佈」無檔可取。初判與重判的程序因此不等，前後兩次判定的一致程度所測不再是同一程序的穩定性，而混入取用條件之差，克里彭多夫⁸⁶所稱穩定性的前提（同一程序隔時重做）在這兩層不成立。另各層兩次判定的時距亦不等：價值層約八週，符號層自初判封存至重判開始逾十六週，穩定性陳述若不分層標明時距，兩層數字不可比。

改法：重判層序改為「價值層居首，相隔不少於四週再作符號層，文化層與場域層兩輪在符號層重判封存之後進行，得讀重判的符號層檔案，取用規定與初判相同」，符號層與價值層仍各有一次居先；枚舉陳述每層並記該層兩次判定之間的實際週數。

**7.【新問題】中等 — 揭示步的清點時點與判定時點相斥，「一句」無界**

位置：「一組並置在一件之內反覆的次數與件間的反覆，由合讀依各條登記分別清點，據此在本輪判定高頻組合是否已滑入巴特所稱的第二系統⁵」；對照「每輪只登一層的觀察項，並在封存之前完成本層的全部判定」「合讀⋯⋯只處理跨層之事，不改動任何一層的判定」。

問題：次數若由合讀清點，本輪封存之前無從判定高頻；合讀又明定不處理單層之事，高頻判定遂無處可作。「並置以校定本的一句為界」，一句以何種標點為界未定，逗號分句與句號句取法不同，組數隨之不同，不可重複。

改法：「一組並置在一件之內與件間反覆的次數，於本輪全表登畢、封存之前依各條登記清點，據此判定高頻組合是否已滑入巴特所稱的第二系統⁵」；「並置以校定本中以句號、問號或歎號收結的一句為界」。

**8.【新問題】中等 — 語言成分四值的替換判準與自舉之例相牴**

位置：「判定以替換為準，能以普通話對應詞替換而語義不變的，記為粵語或普通話的口語成分，膊頭之於肩膀、發夢之於做夢即是；不能替換而兩地通行的，記為港澳書面詞」；「巴士一類兩地書面通行的詞語，亦見於語料庫的校定本」。

問題：巴士可以「公共汽車」替換而語義不變，依此判準應記為口語成分，正文卻以它為港澳書面詞之例，判準與例證相牴（巴士見 W15「偶爾會有一輛綠皮巴士疾馳而過」；膊頭見 W14「搭著祖西的膊頭」，發夢見 W16「莊子發夢變成蝴蝶」，三例語料核對無誤）。又四值之中，普通話口語成分無從「以普通話對應詞替換」，規範書面語亦無判準，替換測試只能分出粵語成分一值。

改法：「語言成分的歸類分兩步：先查石定栩等所列港式中文詞語⁸³，見於該表者記港澳書面詞；餘者以普通話對應詞替換，能替換而語義不變者記粵語口語成分，不能替換者記規範書面語；普通話口語成分以《現代漢語詞典》標〈口〉者為據。膊頭之於肩膀、發夢之於做夢為粵語口語成分，巴士為港澳書面詞，三者皆見於校定本」。

**9.【新問題】中等 — 反例簿與斷裂組態簿歸簿條款重疊，分母口徑未明（第35、34條）**

位置：「兩層同向並存、單層在場與兩層失調三種情形逐件登記，單層在場與兩層失調者入反例簿⋯⋯推翻條件的計數即以此簿為據」；「斷裂組態簿⋯⋯收某一維度的觀察項在本件全無可登之處⋯⋯所收之件不入推翻條件的計數，枚舉時單列，件數與全表並陳」。

問題：一件符號層全無可登而價值層有判定者，既是「單層在場」（入反例簿、入計數），又是「可辨識性維度全無可登」（入斷裂組態簿、不入計數），兩簿條款同時命中而無先後。「不入計數」未言是否仍在分母之內；第二節已定「推翻條件的分母為現行版全表」，此處「件數與全表並陳」是否即此義，須寫明。

改法：「單層在場指符號層與價值層皆有可登之處而判定僅一層成立；一層全無可登者先歸斷裂組態簿，不再作反例判定」；「所收之件不入推翻條件的分子，分母仍為現行版全表，枚舉時單列其件數」。

**10.【新問題】中等 — 位點詞表不閉合、列文森引註承重不合、兩條歸類規則重疊（第14、35條）**

位置：「共識的清單一欄以列文森（Levinson, 1983）所列預設觸發語⁸²為位點，當然、本來、畢竟、難怪、誰不知一類詞語與連⋯都、也不全部一類句式所在的字句」；「只見、原來、心想一類轉入人物視點的詞語」；「傳說、聽說、某人告訴我、據某書記載一類詞語」；「引號、叫做與所謂一類引介語」；「先找出查核位點，即文本自身的場景足以容納該項之處，人群、課室、街市與家族往事的講述皆屬之」；「回歸以前歸長時段，繫於回歸及其前後過渡的事項歸主權時刻」。

問題：(a) 五處位點皆以「一類」收尾，詞表不閉合，他人循同一規則重讀無從得到同一組位點。(b) 列文森所列觸發語為定指描述、敘實動詞、狀態變化動詞、反覆詞、分裂句、時間從句等，不含「當然、畢竟、難怪」一類語氣副詞；「連⋯都」在該書歸常規含義一節而非預設觸發語；引註所承非其所載。(c)「足以容納該項」本身是判讀，位點類型未閉合，缺席判定隨之不可重複。(d) 回歸前的過渡期既屬「回歸以前」又屬「前後過渡」，兩條規則重疊，且理論架構只定一九九九年一點，過渡期起訖此處未寫。

改法：各類位點的詞表與句式表於細讀前寫定、封存，隨判定規則存入語料庫，正文諸處改為「⋯⋯等詞語，詞表見判定規則附表，正文所舉為其中數例」；列文森一句改為「共識的清單一欄以列文森所列預設觸發語⁸²為一類位點，另以標示說話者視為不言自明的語氣副詞與全稱判斷句為一類位點，後者的詞表另立」；查核位點改為「名單於封存時逐項寫定可容納該項的場景類型，查核限於這些類型」；時段規則改為「先判主權時刻：自一九八七年《中葡聯合聲明》簽署至回歸為過渡，繫於回歸及這段過渡的事項歸主權時刻；餘者回歸以前歸長時段，回歸以後歸當下」（起點年份由作者依理論架構定奪，但必須寫出）。

**11.【新問題】中等 — 時程算術未閉合，「研究時程」全文無此表，字數口徑未注（第34條）**

位置：「初判與重判各讀全表五遍，通讀一遍、四層各一遍，全表正文五萬二千三百六十四字，合計約五十二萬字的閱讀量；連同兩次四週與一次八週的時距，細讀自開始至合讀不少於五個月，在研究時程所列的細讀預算之內」；「週數取研究時程所容的上限」；「起訖以校定本為座標，記段序與段內的起字序和訖字序，字序連標點計算」。

問題：(a) 兩次四週與一次八週合計十六週，約三個月又三週，「不少於五個月」尚差五至六週，須由十遍閱讀與登記的工時補足，而工時未寫，五個月無從推得。(b)「研究時程」與「細讀預算」全文無此表：第一節只定「十五至二十部」的規模，第二節稱「前節以細讀深度劃定的預算」亦只指規模，導論無時程；兩處指涉落空，斷言無據。(c) 五萬二千三百六十四字在第二節注「不計標點」，此處未注，而字序「連標點計算」，兩口徑並存卻未明示。其餘數字（四十九頁、二萬三千七百九十八字、八處十字、十六／四／六件、約五十二萬字）與語料庫核對相符，不另列。

改法：「初判與重判各讀全表五遍⋯⋯合計約五十二萬字；以每輪全表登畢不少於一週計，十輪連同兩次四週與一次八週的時距，自開始至合讀不少於二十六週」，刪「在研究時程所列的細讀預算之內」與「週數取研究時程所容的上限」，或在第一節補一句細讀期的月數再回指；「全表正文五萬二千三百六十四字（不計標點）」；「字序連標點計算，與字數不計標點的口徑不同，兩者不互換」。

**12.【落實查核／新問題】輕微 — 術語先用後定義、枚舉漏值、同名異義（第一輪第12條部分未落實；第33條）**

位置：「覆核延至四輪全部封存之後、合讀之前施行」早於「合讀，即把同一文本各層的登記按字句起訖並置核對」；「逐項登記在場、帶過、缺席或不適用」而後文另有「登記為暗指」；「文本把澳門與哪些外部地點相聯，另記一項，空間的缺席依馬西的關係觀界定，即未被納入文本的聯繫網絡」與缺席清單「空間」一欄的「缺席」同名異義。

問題：「合讀」首現仍先於定義；五值列為四值；「空間的缺席」兼指外部聯繫之闕與名單空間項之闕，一詞二義。

改法：首現處改為「覆核延至四輪全部封存之後、各層登記並置核對（下稱合讀）之前施行」，後文定義保留；「逐項登記在場、帶過、暗指、缺席或不適用」；「外部聯繫的闕如依馬西的關係觀界定」。
