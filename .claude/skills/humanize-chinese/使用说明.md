## 项目简介

humanize-chinese 是一个纯 Python 的中文 AI 文本检测与人性化改写工具。核心特点：

- **零 LLM 依赖**：不需要调用任何大语言模型 API，完全本地运行
- **检测 + 改写一体**：先检测 AI 痕迹，再针对性改写
- **多场景支持**：通用 / 学术论文 / 社交媒体 / 风格转换
- **可选 BERT 增强**：集成 BERT 模型提升检测和改写质量
- **可复现**：支持 `--seed` 参数固定随机种子

**基准数据**（HC3-Chinese 200 样本）：

| 指标 | 数值 |
|------|------|
| 融合检测正确率 | 95.5% |
| 平均降分幅度 | -73 分 |
| `--quick` 模式速度 | 10k 字符 0.3 秒 |
| 完整模式速度 | 10k 字符 5 秒 |

## 功能详解

### AI 痕迹检测

```bash
python scripts/detect_cn.py [文件] [选项]
```

**输入**：中文文本文件或 stdin 管道

**输出**：0-100 评分（越高越像 AI），含逐句分析和检测类别明细

#### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `file` | 输入文件路径（可选，不指定则从 stdin 读取） | — |
| `-j`, `--json` | JSON 格式输出 | 关闭 |
| `-s`, `--score` | 仅输出分数 | 关闭 |
| `-v`, `--verbose` | 详细模式（含逐句分析） | 关闭 |
| `--sentences N` | 显示最可疑的 N 个句子 | 5 |
| `--lr` | 仅 LR ensemble 打分（诊断用） | 关闭 |
| `--rule-only` | 仅 rule+stat 打分（legacy 模式） | 关闭 |
| `--scene` | LR 场景：`general` / `academic` / `novel` / `auto` | `general` |

#### 使用示例

```bash
# 基本检测
python scripts/detect_cn.py 论文.txt

# 仅输出分数
python scripts/detect_cn.py 论文.txt -s

# JSON 格式（方便程序处理）
python scripts/detect_cn.py 论文.txt -j

# 详细模式（逐句分析）
python scripts/detect_cn.py 论文.txt -v --sentences 10

# 学术场景检测
python scripts/detect_cn.py 论文.txt --scene academic

# 从管道读取
echo "综上所述，AI技术前景广阔。" | python scripts/detect_cn.py
```

#### 评分机制

检测评分由三层融合而成：

| 层级 | 权重上限 | 说明 |
|------|----------|------|
| 规则层 | ~60 分 | 三段式套路、机械连接词、空洞宏大词、AI 高频词、模板句式等 20+ 维度 |
| 统计层 | ~40 分 | 字符级 trigram 困惑度、DivEye 惊奇度、GLTR rank 分桶、句长 burstiness |
| BERT 层 | 融合 | 可选，BERT 模型判断（见 [BERT 集成](#bert-模型集成)） |

#### 分数等级

| 等级 | 分数范围 | 含义 |
|------|----------|------|
| LOW | 0-15 | 基本无 AI 痕迹 |
| MEDIUM | 15-35 | 轻微 AI 痕迹 |
| HIGH | 35-60 | 明显 AI 痕迹 |
| VERY_HIGH | 60-100 | 高度疑似 AI 生成 |

### 通用改写

```bash
python scripts/humanize_cn.py [文件] [选项]
```

**输入**：中文文本文件或 stdin

**输出**：改写后的文本

#### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `file` | 输入文件路径（可选） | stdin |
| `-o`, `--output` | 输出文件路径 | stdout |
| `--scene` | 场景：`general` / `social` / `tech` / `formal` / `chat` | `general` |
| `--style` | 写作风格（调用 style_cn.py） | — |
| `-a`, `--aggressive` | 激进模式（改写力度更大） | 关闭 |
| `--seed N` | 随机种子（可复现） | — |
| `--best-of-n N` | 运行 N 次取 LR 分数最低的一次（0 关闭） | 10 |
| `--no-stats` | 跳过统计优化 | 关闭 |
| `--no-noise` | 跳过噪声策略 | 关闭 |
| `--quick` | 快速模式（= `--no-stats --no-noise`） | 关闭 |
| `--cilin` | 启用 CiLin 同义词词林扩展 | 关闭 |

#### 使用示例

```bash
# 基本改写
python scripts/humanize_cn.py text.txt

# 快速改写（0.3 秒/10k 字符）
python scripts/humanize_cn.py text.txt --quick

# 激进模式（降分更多）
python scripts/humanize_cn.py text.txt -a

# 保存到文件
python scripts/humanize_cn.py text.txt -o output.txt

# 可复现结果
python scripts/humanize_cn.py text.txt --seed 42

# 多次运行取最优（降分效果更好，但更慢）
python scripts/humanize_cn.py text.txt --best-of-n 20

# 学术场景
python scripts/humanize_cn.py text.txt --scene formal
```

#### 改写流程

系统会先对源文本做预检测分级，根据 AI 评分自动选择改写强度：

| 档位 | 条件 | 改写内容 |
|------|------|----------|
| conservative | AI 评分 < 5 | 仅短语替换 + 标点清理 |
| moderate | 5 ≤ 评分 < 25 | + 句式重组 + bigram 优化 |
| full | 评分 ≥ 25 | 全量（含噪声注入 + 句长随机化） |

完整处理流程：

```
输入文本
  → best_of_n 多次运行（取 LR 最优）
  → 预检测分级（自动选择强度）
  → Pass 1 结构清理（三段式移除 + 短语替换）
  → Pass 2 深度重组（句式变换 + 句子拆合）
  → Pass 3 节奏多样性（标点 + 词汇 + Zipf 扰动）
  → Pass 4 场景特定（口语化 + 段落调整）
  → 困惑度提升（低频 bigram + 噪声表达）
  → 过渡词密度控制
  → 最终验证循环
  → 输出改写后文本
```

## Python API 调用

所有模块都可以作为 Python 库直接 `import` 调用，无需通过命令行。

### 快速示例

```python
import sys
sys.path.insert(0, 'scripts')

# 1. 检测 AI 痕迹
from detect_cn import detect_patterns, calculate_score, score_to_level
issues, metrics = detect_patterns("综上所述，AI技术前景广阔。")
score = calculate_score(issues, metrics)
print(f"AI 评分: {score}, 等级: {score_to_level(score)}")

# 2. 改写文本
from humanize_cn import humanize
result = humanize("综上所述，AI技术前景广阔。", scene='general')
print(result)

# 3. 学术降重
from academic_cn import humanize_academic
result = humanize_academic("本文旨在探讨人工智能的发展趋势。", aggressive=False)

# 4. 风格转换
from style_cn import apply_style
result = apply_style("今天天气真好", style_name='xiaohongshu')

# 5. BERT 检测
from bert_detector import bert_detect_score
score = bert_detect_score("综上所述，AI技术前景广阔。")
# 返回 0-100 或 None（模型不可用时）

# 6. 语义保镖
from semantic_guard import safe_rewrite
result = safe_rewrite("原文", "改写文", threshold=0.85)
# 语义不足时自动回退原文
```

### 检测模块 detect_cn

```python
from detect_cn import (
    detect_patterns,      # 核心检测引擎
    calculate_score,      # 计算分数
    score_to_level,       # 分数转等级
    analyze_sentences,    # 逐句分析
    format_output,        # 格式化输出
    split_sentences,      # 拆分句子
    count_chinese_chars,  # 统计中文字符数
)
```

#### detect_patterns(text)

扫描 20+ 类 AI 特征，返回检测问题和指标。

```python
issues, metrics = detect_patterns(text)
# issues: defaultdict — 各检测类别的命中详情
# metrics: dict — 统计指标（困惑度、burstiness 等）
```

#### calculate_score(issues, metrics) → int

根据检测结果计算 0-100 的 AI 概率分数。

```python
score = calculate_score(issues, metrics)
# 0-100，越高越像 AI
```

#### score_to_level(score) → str

```python
level = score_to_level(score)
# 'very_high' | 'high' | 'medium' | 'low'
```

#### analyze_sentences(text, top_n=5) → list[dict]

找出最像 AI 写的 N 个句子。

```python
sentences = analyze_sentences(text, top_n=10)
# [{'text': '...', 'score': 85, 'reasons': ['三段式结构', 'AI高频词']}, ...]
```

#### format_output(...)

格式化检测结果为可读文本或 JSON 字符串。

```python
output = format_output(
    issues, metrics, score,
    sentences=None,       # analyze_sentences 的结果
    as_json=False,        # True 则输出 JSON
    score_only=False,     # True 则仅输出分数
    verbose=False         # True 则包含逐句分析
)
```

#### humanize(text, ...) → str

**主入口函数**，按顺序执行全部人性化改写。

```python
result = humanize(
    text,                          # 待改写文本
    scene='general',               # 场景: general/social/tech/formal/chat
    aggressive=False,              # 激进模式
    seed=None,                     # 随机种子（可复现）
    best_of_n=10                   # 运行 N 次取 LR 最优（0 关闭）
)
```

系统会先对源文本做预检测分级，自动选择改写强度：
- `conservative`（AI 评分 < 5）：仅短语替换 + 标点清理
- `moderate`（5 ≤ 评分 < 25）：+ 句式重组 + bigram 优化
- `full`（评分 ≥ 25）：全量（含噪声注入 + 句长随机化）

#### 单步策略函数

每个策略都可以单独调用，适合自定义流水线：

```python
text = "首先，我们需要提高效率。其次，应该降低成本。最后，实现可持续发展。"

# 移除三段式结构
text = remove_three_part_structure(text)

# 短语替换（casualness 控制口语化程度 0-1）
text = replace_phrases(text, casualness=0.3)

# 低频 bigram 注入（strength 控制强度）
text = reduce_high_freq_bigrams(text, strength=None, scene='general')

# 噪声表达插入（density 控制密度）
text = inject_noise_expressions(text, density=None, style='general')

# 句长随机化
text = randomize_sentence_lengths(text, aggressive=False, seed=42)

# 过渡词密度控制（target: 每千字目标数量，默认 6.0）

```

## BERT 模型集成

BERT 是可选增强功能。不安装 BERT 模型时，系统使用规则 + 统计的融合评分，完全可用。安装 BERT 后可获得更精准的检测和更自然的改写。

### 三个 BERT 角色

| 角色 | 模型文件 | 需要训练？ | 作用 |
|------|----------|------------|------|
| ① AI 检测器 | `bert_model_anx/model.onnx` | ✅ 已训练 | 判断文本是否 AI 生成 |
| ② 句式评分器 | `bert_base_chinese_mlm.onnx` | ❌ 不需要 | 改写时从多个候选中选最自然的 |
| ③ 语义保镖 | `bert_base_chinese.onnx` | ❌ 不需要 | 改写后检查是否改变了原意 |

### 下载与导出模型

句式评分器和语义保镖使用预训练的 `bert-base-chinese`，不需要训练。运行以下脚本下载并导出：

```bash
cd scripts
python download_bert.py
```

执行过程：

```
[1/4] 下载 bert-base-chinese ...
[2/4] 导出 MLM 模型（句式评分器）... ✅ 已保存 (420MB)
[3/4] 导出 BertModel（语义保镖）...     ✅ 已保存 (420MB)
[4/4] 完成！
```

**产物**：

| 文件 | 大小 | 用途 |
|------|------|------|
| `bert_base_chinese_mlm.onnx` + `.data` | ~420MB | 句式评分器 |
| `bert_base_chinese.onnx` + `.data` | ~420MB | 语义保镖 |
| `bert_base_chinese/` | — | Tokenizer 文件 |

> **注意**：此脚本需要 `torch` 和 `transformers`（仅导出时需要，推理不需要）。

### 融合评分公式

BERT 检测器集成后，最终分数由多路融合而成：

| 文本类型 | 公式 | 说明 |
|----------|------|------|
| 长文本（≥100 字） | 0.1×规则 + 0.4×LR + 0.5×BERT | 三路全部参与 |
| 短文本（<100 字） | 0.4×规则 + 0.6×BERT | 跳过 LR（统计特征不够） |
| BERT 不可用时 | 0.2×规则 + 0.8×LR | 自动降级为原有方式 |

### 训练自定义检测器

如需训练自己的 BERT 检测模型：

```bash
python scripts/train_bert_detector.py --data_dir ./training_data --output_dir ./my_model
```

**数据格式**（`data_dir` 下支持四种格式）：

1. `data.jsonl`：每行 `{"text": "...", "label": 0 或 1}`（0=人类，1=AI）
2. `data.csv`：包含 `text`, `label` 两列
3. `hc3_all.jsonl`：HC3 原始格式
4. `ai_texts/` + `human_texts/` 目录结构

**训练参数**：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--data_dir` | 训练数据目录（**必填**） | — |
| `--output_dir` | 模型输出目录 | `./bert_model` |
| `--epochs` | 训练轮数 | 3 |
| `--batch_size` | 批大小 | 16 |
| `--max_length` | 最大序列长度 | 128 |
| `--learning_rate` | 学习率 | 2e-5 |
| `--quick` | 快速测试（每类 50 条） | 关闭 |
| `--fp16` | FP16 量化导出 | 关闭 |

训练完成后，将模型文件复制到 `scripts/bert_model_anx/` 目录，并在 `config.json` 中配置 `bert_detector.model_dir`。

### Q: 不安装 BERT 模型能用吗？

可以。BERT 是可选增强。不安装时系统自动降级为规则 + 统计的融合评分，功能完整。

### Q: `--quick` 和完整模式有什么区别？

`--quick` 跳过统计优化（困惑度引导选词）和噪声策略（句长随机化），速度提升约 15 倍，但降分效果略弱。适合快速预览。

### Q: `--best-of-n` 是什么原理？

运行 N 次改写，每次用不同的随机种子，然后对每次结果做 LR 检测评分，取分数最低（最像人类）的版本。默认 N=10。

### Q: 改写后分数反而升高了？

可能原因：
- 过度改写注入了新的 AI 模式
- 原文本身已经很自然（AI 评分低），改写反而增加了痕迹
- 解决方案：降低 `--aggressive` 或使用 `--min-score` 只改高分段落

### Q: 如何让结果可复现？

使用 `--seed` 参数固定随机种子：

```bash
python scripts/humanize_cn.py text.txt --seed 42
```

### Q: ONNX 模型文件只有 1-2MB？

导出失败。PyTorch 2.11+ 默认使用 dynamo 导出器，不会嵌入权重。确保 `download_bert.py` 中包含 `dynamo=False` 参数。

### Q: 学术降重和通用改写有什么区别？

学术降重（`academic_cn.py`）针对论文场景优化：
- 10 个检测维度（段落均匀性、连接词密度、主题扩散度等）
- 126 条学术专用替换规则
- hedging 注入（"可能"、"或许"等）
- 结构变异（调整段落顺序）

通用改写（`humanize_cn.py`）更通用，支持多场景，改写力度更大。
