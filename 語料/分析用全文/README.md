# 分析用全文（W01–W26）

第三章第二節核心語料表二十六件的分析用文本。每件一檔，正文逐字依原刊，可直接用於細讀、檢索、計數與引文核對。整理與核對完成於 2026-10-11。

## 檔案格式

每檔分兩部分，以一行「========================================」隔開。

- **檔頭**：篇名、作者、所在（刊物、期次、印刷頁碼）、語料表登記（來源碼｜年份｜生產方式）、所據文本（澳門虛擬圖書館或作者網站網址、PDF 頁）、整理與核對方式及個案說明、頁碼標記說明、正文字數、核對日期。
- **正文**：一個自然段一行。

## 正文標記

| 標記 | 含義 |
|---|---|
| 〔頁N〕 | 原刊印刷頁碼，置於該頁正文起處；段落跨頁時置於段中斷頁處。位數照原刊（如〔頁03〕〔頁9〕〔頁061〕）。 |
| 〔頁N·推定〕 | 原刊無印刷頁碼（《童一枝筆》第13期全刊無頁碼、無目錄），依同刊各期編頁例推定。引用時宜並注 PDF 頁。 |
| 〔導語：版面摘句，與正文重複〕 | 篇名下的版面摘句（W23、W24），內容與正文某句重複，做字頻、詞頻等計量時宜排除。 |
| 〔圖中文字〕 | 插圖內屬於故事內容的文字（W06 黑板上「海角遊魂」）。 |

W01–W04 為網頁轉載，無頁碼，不設頁碼標記。「正文字數」不計標點、空白與上列標記。

## 逐字原則

正文一字不改：原刊錯字、漏字、異體字（着／著、裡／裏、説／說、彷佛、分岐等）、全形半形標點一律照錄，不統一、不改正。疑誤處在檔頭「整理與核對」欄註明「原刊如此，照錄」，正文不加註。引用時以本檔為準，必要時對照存檔原頁（見下）。

## 三類文本的整理方式

**網頁轉載（W01–W04）**：取作者網站文章正文，刪網站導航、上下篇連結與 cookie 說明。2026-10-11 以 crawl4ai 重爬，正文與 2026-09 存檔逐字一致。分段依網頁原有段落與換行（網頁在段內以換行斷句者亦各成一行）。報端原版未見，全文出自作者自建網站，記「來源自涉」旗標（見第三章第二節）。

**出版方文字層（W07–W13、W18–W26）**：《童一枝筆》各期在澳門虛擬圖書館的「線上文字」即出版方排版 PDF（Adobe Illustrator 輸出）的內嵌文字，非掃描辨識，字形可靠。2026-10-11 重爬各期頁面與 PDF，存檔文字逐字一致。整理時逐頁對照原刊頁影，核對完整性、字形映射與閱讀次序；只刪頁碼、欄目書眉、與檔頭重複的篇名署名及版面符號（▉），並以腳本驗證整理稿相對底本「只有刪除、沒有增改」。唯一的例外是 W23、W24 的版面摘句：文字層把它排在正文中段，已移回篇名下並加標記，經腳本驗證移動之外逐字不變。

**掃描逐字轉錄（W05、W06、W14–W17）**：原刊為掃描影像，無文字層。每頁由兩次獨立轉錄逐字完成，互不參看；兩讀逐字比對後，分歧處對照原始掃描影像放大裁決，另以機器 OCR 逐行核查有無漏行。六件四十九頁，正文 23798 字，兩讀分歧共八處（十字），全部依原頁裁定，裁決紀錄見 `_核對/裁決紀錄.md`。
