## 分析用全文/（W01–W26，細讀與引文用）

二十六件統一格式的純文字：檔頭記出處、所據文本與整理方式，正文一段一行，以〔頁N〕標原刊印刷頁碼，逐字照錄原刊（錯字、異體、標點不改）。掃描六件經兩次獨立逐字轉錄加原頁裁決，其餘以出版方文字層或網頁正文為底本、腳本驗證只刪雜訊不改正文。格式、標記與核對方式見該目錄 README，轉錄底稿、裁決紀錄與腳本在 `分析用全文/_核對/`。
