# 名錄_街道與分區：市政署街道名冊取用方式、堂區全列；統計暨普查局統計分區全列

- 取用日期：2026-11-11

## 一、市政署（IAM）街道名冊

### 1. 取用方式與狀態
- **線上「街道名冊」整冊（可查全部街名的官方名冊）：未能取得。** 原因：市政署官網（https://www.iam.gov.mo/ ，Nuxt 單頁應用）全站地圖 https://www.iam.gov.mo/sitemap.xml（1,148 條）及站內選單資料 https://www.iam.gov.mo/data/sitemap.json（325 個欄目 id）中，與「街道」相關者僅有 macaostreets（澳門街道專題，/c/macaostreets/menulist）及其三個子欄目、streetbanner / streetbannerloc（街道橫額），無「街道名冊」「街道名稱查詢」或街名下載檔；出版物資料 https://www.iam.gov.mo/data/publication_c.json（170 筆，《市政資訊》等）中亦無街道名冊。手機應用程式清單（/data/apps_c.json：市政在線、街市通、工程資訊網等）亦無。robots.txt 禁止 /c/web/search/ 等站內搜尋路徑，本次未使用站內搜尋。
- **已取得的市政署街道相關官方資料（非整冊名冊）：**
  - 「澳門街道」專題首頁：https://www.iam.gov.mo/c/macaostreets/menulist （選單資料最後修改 2025-12-30T09:40:58）
  - 「堂區街道歷史」（parishstreethistory）：頁面 https://www.iam.gov.mo/c/parishstreethistory/itemlist ；資料檔 https://www.iam.gov.mo/data/parishstreethistory_c.json （102 條街道，每條含 title、content、freguesiaCode、freguesia、lastModDate；資料最後修改 2025-11-24T10:08:04）；葡文版 https://www.iam.gov.mo/data/parishstreethistory_p.json 。可視為市政署「有街道歷史介紹的街道」子集，**不是**全部街名。
  - 「澳門街道主題路線」（macaostreetsrouteintro）：https://www.iam.gov.mo/c/macaostreetsrouteintro/itemlist ；資料 https://www.iam.gov.mo/data/macaostreetsroute_c.json （19 條路線）、景點 https://www.iam.gov.mo/data/macaostreetsloc_c.json
  - 「老街回憶」（oldstreetmemories）：https://www.iam.gov.mo/c/oldstreetmemories/thumbnail ；資料 https://www.iam.gov.mo/data/oldstreetmemories_c.json
- **可下載版本**：市政署官網未見街道名冊下載檔（PDF/XLS）。版本年份：不適用／未能取得。
- **替代官方查詢系統（非市政署）**：土地工務局（DSSCU，前地圖繪製暨地籠局 DSCC 業務已併入；www.dscc.gov.mo 現轉址 www.dsscu.gov.mo）「澳門街道門牌查詢系統」 https://webmap.gis.gov.mo/AddressSearch/chn/ ，頁面說明：「土地工務局在網上地圖的基礎上，開發了本系統…可查詢街道和建築物的繁體中文及葡文對照名稱、特定建築物所在的街道及首末門牌…」。為互動查詢（DWR 介面 findStreetList / findHotStreetList / findBuildingByStreetNameAndDoorNo，按地區＋關鍵字分頁），未見整冊下載；亦無版本年份標示。另 GIS 入口 https://webmap.gis.gov.mo/ → https://webmap.gis.gov.mo/MapGIS/index.html（澳門地圖通，JS 應用）。
