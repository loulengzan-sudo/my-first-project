# 拆法表　第一版（2026-11-11 寫定並存檔）

同一字句上兩層登記相交時的拆分規則。依理論架構同一文本片段不兩處計入的約定：評價語歸話語一方，所裝配的符號組合歸符號一方。

1. 評價語直接修飾符號名稱（著名的大三巴、美麗的西灣）：名稱字串歸符號層，定語歸價值層，兩層互記對方的起訖。
2. 神話化之拆：結局獎懲所認可的評價語與並置組落在同一句，評價語歸價值層的獎懲落點，並置組歸符號層，兩層互記起訖；同一句既充並置組成員又充被評價事項者，名稱字串只計符號一方，被評價事項以該字串為落點比對之用而不另計符號。
3. 分期詞之拆：回歸、賭權開放、列入世遺一類分期詞，在符號層計為史事符號，在文化層計為時段的講述，兩層各自登記，起訖相同不計相交；分期詞所帶的評價語歸價值層。
4. 總括語（都、全、一帶、這些及其後的類名）歸符號層並置組的連為一體手段，同一總括語若含評價語（這些美麗的地方）則評價語歸價值層。
5. 表未覆蓋的重疊記入判定邊界案例簿；修訂經修訂簿並對全表重查。
